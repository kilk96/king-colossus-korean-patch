# 투기왕 킹콜로서스 — 메가드라이브 한글 패치

메가드라이브 일본판 《투기왕 킹콜로서스》의 대사·메뉴·시스템 문구와 이름 입력을 한글화한 비공식 팬 번역 패치입니다. 현재 배포 버전은 **v1.0.1**입니다.

## 다운로드

[최신 패치 다운로드](https://github.com/kilk96/king-colossus-korean-patch/releases/latest)의 **Assets**에서 **`king-colossus-ko-v1.0.1.zip`**을 받아 압축을 풀어 주세요.

원본 게임 파일은 별도로 준비해야 합니다. GitHub의 `Source code` 압축 파일과 별도 PNG 미리보기는 패치 적용에 필요하지 않습니다.

## 적용 방법

1. 보유하신 일본판 원본 ROM을 복사하고, 아래 **지원 원본과 파일 확인**의 크기와 SHA-256이 일치하는지 확인해 주세요.
2. **xdelta 3.2 이상**을 지원하는 도구에서 원본 ROM과 ZIP 안의 `king-colossus-ko-v1.0.1.xdelta`를 선택해 주세요.
3. 결과를 `King Colossus Korean v1.0.1.bin`처럼 원본과 다른 이름으로 저장해 주세요. 이전 한글판을 사용하셨어도 패치는 일본판 원본에 적용해 주세요.
4. 결과 파일의 크기와 SHA-256을 확인한 뒤 메가드라이브 에뮬레이터에서 실행해 주세요. 기존 저장은 먼저 백업해 주세요.

## 번역·확인 범위

- 대사·선택지·메뉴·상태·장비·저장·인명·투기장 관련 문구를 한글화했습니다. 이름은 준비된 한글 109종에서 최대 4글자를 선택할 수 있습니다.
- 제작자가 엔딩까지 진행하고 엔딩 버그 수정과 이름 입력을 확인했습니다. 엔딩의 두 분기와 이름 입력·저장·재시작 후 불러오기도 별도로 확인했습니다.
- **v1.0.1 변경:** 주인공의 누나 플로라의 대사 6개를 다정한 반말로 통일했습니다. 수정 문구의 화면 표시와 글꼴을 확인했으며, 일부 장면에는 테스트용 진행·체력 조건을 사용했습니다. 이번 수정판으로 전체 게임을 다시 완주하지는 않았습니다.

## 실행과 저장

확인한 실행 환경은 **BizHawk 2.11.1 / GPGX**입니다. GPGX는 BizHawk에서 메가드라이브 게임을 구동하는 엔진입니다.

일본어 가나 이름으로 저장한 게임은 한글판에서 이름이 다른 글자로 표시될 수 있어 새 게임을 권장합니다. 기존 저장을 사용하실 때는 먼저 백업해 주세요. 에뮬레이터가 특정 순간을 저장하는 **순간 저장(세이브스테이트)**은 게임 내 저장과 별개이며, 구버전 순간 저장의 호환은 보장하지 않습니다.

## 알려진 제한

- 장비창을 겹쳐 열었다 닫을 때 순간 글자 변형과 간헐적인 입력 지연이 남아 있습니다.
- 투기장 무기 구매·아이템 사용 중 겹치는 창의 글자 변형 제보는 추가 확인이 필요합니다.
- 타이틀 로고와 `NAME ENTRY`, `CLR/DEL/END`, `HP/MP` 등 원래 영문 표기는 유지합니다.
- 모든 조건별 장면과 실제 기기·다른 에뮬레이터까지 확인하지는 못했습니다.

## 지원 원본과 파일 확인

SHA-256은 파일 내용이 지원 판본과 같은지 확인하는 값입니다. 파일명보다 아래 크기와 SHA-256을 기준으로 확인해 주세요.

| 항목 | 값 |
|---|---|
| 지원 원본 | King Colossus (Japan), 일본판, 헤더 없는 BIN |
| 원본 크기 | 1,048,576바이트 |
| 원본 SHA-256 | `c318d3e353e51cdcd6633b68dd6f2701d4cabfdcb6d4393ee6a9bfaa97a50194` |
| 적용 결과 크기 | 1,048,576바이트 |
| 적용 결과 SHA-256 | `0be8a1990e841b9db72940c3a78fc2e2fbff21a8a6f71da56bc3347201a14364` |

헤더 없는 BIN은 파일 앞에 부가 정보가 붙지 않은 일반 게임 이미지 형식입니다. SMD 파일은 직접 사용할 수 없으며, 확장자만 바꾸어도 지원 형식으로 바뀌지 않습니다.

Windows PowerShell에서 다음 명령의 파일명을 실제 파일명으로 바꾸면 SHA-256을 확인할 수 있습니다.

```powershell
Get-FileHash "KING COLOSSUS (J).bin" -Algorithm SHA256
```
